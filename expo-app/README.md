# Sninat • Application Mobile Expo Go (React Native)

Cette application est prête pour **Expo Go** et fonctionne simultanément sur **Apple iOS** (iPhone / iPad) et **Google Android**.

## 🚀 Démarrage Rapide

1. Ouvrez votre terminal et rendez-vous dans le dossier `expo-app` :
```bash
cd expo-app
```

2. Installez les dépendances :
```bash
npm install
```

3. Démarrez le serveur Expo :
```bash
npx expo start
```

## 📱 Tester sur votre téléphone réel

### Pour Apple iOS (iPhone)
1. Installez l'application **Expo Go** depuis l'App Store Apple.
2. Ouvrez l'application **Appareil photo** native de votre iPhone.
3. Visez le QR code affiché dans votre terminal.
4. Touchez la bannière pour ouvrir directement l'application dans Expo Go.

### Pour Android
1. Installez l'application **Expo Go** depuis le Google Play Store.
2. Ouvrez **Expo Go** et touchez **Scan QR code**.
3. Scannez le QR code de votre terminal.

- **Portail d'entrée 3 profils** : Patient / Visiteur, Chirurgien-Dentiste, Prothésiste Dentaire.

- **Support bilingue** : Français & Arabe marocain.
